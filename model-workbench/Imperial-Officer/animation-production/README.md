# Officer animation workbench

See [asset, animation and validation notes](../../../docs/IMPERIAL_GUARDSMAN_OFFICER.md).

Open `Officer-Animations.blend` for editable parts and named actions. Open
`Officer-Native-Animation-Review.blend` to inspect the exported asset.
Select the desired action in the Action Editor; NLA library tracks are muted.
Scene playback is 60 fps; native clips preserve their recorded sample rate.
